ตั้งค่า AI API

ตั้งค่าการเชื่อมต่อ AI สำหรับบัญชีนี้

การเชื่อมต่อ

Gemini เชื่อมต่อ API ของ Google กรุณาเปิดอนุญาตปลายทางนอกเครื่อง และกรอก API key จาก Google AI Studio

ระบุ URL ที่เครื่องรันระบบร้านเข้าถึงได้ โดย localhost หมายถึงเครื่องรันระบบร้าน
ใช้ชื่อโมเดลตามที่บริการปลายทางระบุ
ไม่จำเป็นสำหรับบริการในเครื่องที่ไม่ได้เปิดการยืนยันตัวตน
เริ่มใช้งาน
  1. เปิด AI Server และเตรียมโมเดลที่ต้องการ
  2. เลือกบริการและระบุ Base URL
  3. ทดสอบการเชื่อมต่อ แล้วเลือกชื่อโมเดล
  4. กดบันทึกการตั้งค่า
ค่าตั้งต้นในเครื่อง

Ollama

http://localhost:11434

LM Studio

http://localhost:1234/v1

การทดสอบเรียกดูรายชื่อโมเดลเท่านั้น ไม่ส่งภาพหรือข้อมูลคำสั่งซื้อ

Gemini: กรอก API key แล้วโหลดรายชื่อโมเดลที่บัญชีใช้งานได้

เมื่อเปิดใช้ AI รูปภาพที่ครอปจะถูกส่งไปยังบริการที่เลือก ส่วน Excel ส่งเฉพาะหัวคอลัมน์และตัวอย่างรูปแบบที่ปกปิดข้อมูลจริงแล้ว ระบบไม่เปลี่ยนโมเดลให้เอง
